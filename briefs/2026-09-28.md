## Red flags
- Reported (security, open): Error text returned to remote callers can include the server's file paths and internal details. [py#7385: A2aAgentExecutor sends the raw exception text to the A2A caller when t](https://github.com/google/adk-python/issues/7385)
- Reported (side-effects, open): After a connection failure the tool call is resent, so a tool that changes data may run twice. [go#1689: mcptoolset: CallTool resends a tool call after a connection failure, s](https://github.com/google/adk-go/issues/1689)
- Reported (side-effects, open): Replying to a confirmation or consent request restarts the workflow, rerunning finished steps while the requested tool never runs. [go#1658: workflow: a reply to a tool confirmation or consent request restarts t](https://github.com/google/adk-go/issues/1658)
- Reported (data-loss, open): Final streaming replies ending in Chinese punctuation are treated as partial and never saved to the session history. [java#1608: spring-ai Streaming responses ending with CJK punctuation 。！？ are misc](https://github.com/google/adk-java/issues/1608)
