## Red flags
- Reported (security, open): A2aAgentExecutor publishes raw exception text to the peer, bypassing t. [py#7315: A2aAgentExecutor publishes raw exception text to the peer, bypassing t](https://github.com/google/adk-python/issues/7315)
- Reported (data-loss, open): Editing a file can permanently replace bytes elsewhere in it that are not valid text, and the tool reports success. [py#7314: EditFileTool permanently destroys non-UTF-8 bytes outside the edited r](https://github.com/google/adk-python/issues/7314)
- Reported (security, open): Login tokens and client secrets can be written in plain text to trace data sent to monitoring backends by default. [py#7311: safe json serialize dumps AuthCredential secret fields into span attri](https://github.com/google/adk-python/issues/7311)
- Reported (security, open): Different users with the same local session ID can share one remote conversation, so one user's data may reach another. [py#7305: RemoteA2aAgent can collide distinct users when forwarding session id a](https://github.com/google/adk-python/issues/7305)
- Reported (data-loss, open): The two migrate session paths disagree on v0 event timestamps. [py#7300: The two migrate session paths disagree on v0 event timestamps](https://github.com/google/adk-python/issues/7300)
