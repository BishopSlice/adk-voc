## Red flags
- Reported (security, open): Model-supplied relative paths can reach files outside the intended workspace inside remote sandboxes, allowing reads and writes beyond it. [py#7699: Path traversal in sandbox Environments: model-supplied .. paths escape](https://github.com/google/adk-python/issues/7699)
- Reported (security, open): Configured credentials may be sent to a different host when the tool server issues a redirect. [go#1965: tool/mcptoolset: credential forwarded across cross-host redirect — htt](https://github.com/google/adk-go/issues/1965)
- Reported (security, open): Different app and user identifiers can map to the same stored artifact, so one scope may read or delete another's. [py#7706: InMemoryArtifactService aliases distinct app/user scopes when identifi](https://github.com/google/adk-python/issues/7706)
- Reported (safety-gate, open): File deletion approval is a value the model itself supplies, so files can be deleted with no human approval. [py#7655: delete files confirmation is a model-controlled tool argument](https://github.com/google/adk-python/issues/7655)
- Reported (side-effects, open): A workflow step that produces no output can run again after resume, repeating actions such as emails or charges. [py#7666: Workflow: a node that returns None runs again when the workflow resume](https://github.com/google/adk-python/issues/7666)
